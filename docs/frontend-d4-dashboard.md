# 프론트 D4 메인 Dashboard

## 1. 목표

D4는 프로젝트 메인 화면에서 지원 사이트와 금융 업무를 사용자가 직접
선택하고, 두 항목을 모두 선택한 뒤 업무 시작을 준비하는 1차 Dashboard를
제공한다. 실제 세션 생성 API, WebSocket 및 금융거래는 실행하지 않는다.

## 2. 화면 구성

- 공통 `AppLayout`과 D3의 `Text`, `Panel`, `Button`, `StatusBadge`,
  `NoticeBox`를 사용한다.
- 초기 화면 계약은 `SESSION_CREATED`, `INITIAL_SCREEN`, 연결 안 됨,
  로딩 아님 상태를 사용한다.
- 지원 사이트와 업무는 각각 실제 radio group으로 제공한다.
- 선택 결과와 실제 거래가 발생하지 않는 데모 환경임을 텍스트로 안내한다.

## 3. D4 프론트 로컬 모델

지원 사이트는 현재 한 개다.

| siteId | 표시명 | 환경 | 지원 업무 |
| --- | --- | --- | --- |
| `demo-bank` | 금융길잡이 데모뱅크 | 데모 환경 | `OPEN_DEPOSIT`, `TRANSFER_MONEY` |

업무 타입은 다음 두 값을 사용한다.

- `OPEN_DEPOSIT`: 예금 가입
- `TRANSFER_MONEY`: 계좌이체

이 값은 D4 프론트 로컬 선택 계약이다. AI Engine의 `DEPOSIT`,
`TRANSFER`로 변환하는 과정은 D5 이후 통합 계층에서 처리한다.

## 4. 선택과 시작 조건

- 사이트와 업무는 사용자가 직접 선택한다.
- 사이트를 선택하기 전에는 업무 목록을 볼 수 있지만 업무 radio는
  비활성화된다.
- 사이트 변경 후 기존 업무가 새 사이트에서 지원되지 않으면 업무 선택을
  초기화한다.
- 사이트와 업무를 모두 선택하기 전에는 `선택한 업무 시작` 버튼에 실제
  `disabled`가 적용된다.
- 선택 상태는 radio의 checked 상태, 테두리와 `선택됨` 또는 `선택 전`
  텍스트를 함께 사용해 전달한다.

## 5. D4 시작 동작

시작 버튼은 선택한 `siteId`와 `taskType`을 `onStart` 콜백 경계로 한 번
전달한다. D4에서는 API, WebSocket 또는 데모사이트 이동을 실행하지 않고
`선택한 업무를 시작할 준비가 완료되었습니다.`라는 로컬 상태만 안내한다.
`onStart`가 없어도 화면은 오류 없이 동작한다.

## 6. D5 연동 경계

D5에서 `onStart` 선택값을 세션 생성 API에 연결할 예정이다. 현재 공통
`contracts/api.ts`의 생성 요청은 `siteId`, `initialUrl`을 사용하지만 실제
Backend의 생성 요청은 `userRequest`를 사용한다. WebSocket URL을 포함하는
응답 구조도 실제 Backend와 공통 계약 사이에 차이가 있으므로 연동 전에
개발자 B와 요청·응답 계약을 확정해야 한다.

기존 URL 직접 입력용 Zustand 상태와 `orchestratorClient`의 로컬 stub은
D4에서 삭제하거나 변경하지 않는다. 현재 Dashboard에서만 사용하지 않으며
후속 통합 정리 대상으로 남긴다.

## 7. 기존 Mock과 접근성

`FrontendWireframeGallery`와 관련 테스트는 삭제하지 않는다. 앱 기본
진입점에서만 제외한다.

- 제목은 28px 이상, 주요 안내는 18px 이상을 사용한다.
- 선택 영역은 최소 48px 이상의 클릭 공간을 제공한다.
- 실제 radio와 button을 사용해 키보드 기본 동작을 유지한다.
- 시작 버튼은 D3 대형 버튼 기준인 최소 56px을 사용한다.
- `focus-visible`과 선택 텍스트를 제공하며 색상만으로 상태를 전달하지 않는다.
- 민감정보는 표시하거나 상태에 저장하지 않는다.
- 실제 금융거래가 발생하지 않는다는 안내를 항상 표시한다.

## 8. D4 제외 범위

- 세션 생성 REST API와 WebSocket 연결
- 데모사이트 이동과 실제 금융 기능
- AI Engine 업무 타입 변환
- 브라우저 스트림, 위험 경고와 최종 승인
- 비밀번호, OTP 및 계좌번호 입력
- 기존 Zustand와 공통 상태·이벤트·API 계약 변경
